somnium

Persistent project agents for brand developers. The brand developer says "make the landing warmer." The agent does the rest — the engineering is invisible.

The problem

Terrarium is a well-governed machine. The governance is built by and for engineers. Feature branches, PRs, rebase, merge gates. moon ci, lefthook, conventional commits, GPG signing. ArgoCD gitops, Helm charts, kaniko builds. Linear tickets, critpath sweeps, lineage blocks.

Marc and Laura — the brand developers — cannot use this machine. They shouldn't have to. The brand canon, the design tokens, the component library — all of it is for them. But the surface to interact with it is an intimidating backpanel of enterprise dev tools.

The vision

Every node gets two things: a live shared dev environment — an always-up preview at a stable URL (<node>.preview.cerebral.work), automatically rebuilt on every change. No npm run dev, no wrangler, no kubectl. Just a URL that's always live.

And a persistent project agent — one per node — that is the node's dedicated operator. It lives in the node's repo, knows its canon, and translates brand-developer intent into the engineering operations the node requires.

brand developer → "make the lab landing warmer — less amber, more cream"

project agent → reads canon · adjusts tokens · builds · commits · pushes · previews

brand developer → "preview ready: lab.preview.cerebral.work. approve to ship."

production → ArgoCD syncs · lab.cerebral.work is warmer now.

What they see

Three surfaces. No backpanel.

  1. The live preview — always on. The running app at a stable URL. Source of truth for "what does this project look like right now."
  2. The change timeline — a simple web page. What changed, is it ready, do you approve. No git hashes, no PR numbers, no CI logs.
  3. The conversation — chat or voice. Plain language. Previews, approvals, results. The same interaction model the operator uses — scoped to one project, stripped of engineering vocabulary.

What they never see

  • git — branches, commits, rebase, merge
  • github — PRs, reviews, CI status checks
  • argocd / helm / kubectl / kaniko
  • openbao / external-secrets
  • linear — the agent files tickets, the brand developer doesn't manage them
  • wrangler / workers config / KV / D1 bindings
  • the terminal — unless they want to

What the agent does

For each request, the persistent project agent:

  1. interprets intent against the node's canon, design tokens, and voice rules
  2. creates a worktree — isolated from the main workspace
  3. edits only src/ — tokens, components, styles
  4. builds — validates the change compiles and passes realm-lint
  5. commits + signs — conventional commit, GPG, invisible
  6. pushes the branch and opens a PR — invisible
  7. deploys a preview — auto-rebuilt from the branch, posts the URL
  8. waits for CI — green means ready
  9. asks for approval — a simple approve / adjust / reject card
  10. on approve — merges. Canon changes require Marc or Laura sign-off.
  11. on merge — ArgoCD syncs. Reports "shipped."
  12. files the Linear ticket — linked to the commit, status updated automatically

What already exists

  • terrarium monorepo — moon, node templates, lineage blocks, canon
  • @cerebral/design — tokens, theme CSS, components, realm-lint
  • @cerebral/gate — estate-wide auth, HMAC session cookie
  • cloudflare workers — wrangler configs for lab, design, dreams
  • argocd gitops — unsigned-paas, auto-sync
  • linear MCP — ticket filing and updates
  • herdr — pane management, agent state, cross-agent messaging
  • voicemode — voice interaction

New:

  • preview plane — per-branch CF Pages preview URLs
  • persistent agent — one per node, durable, always on call
  • the studio — studio.cerebral.work, the brand developer's entire interface

Naming

The dreaming line. Persistent agents that dream alongside brand developers — always-on, always-previewing. The neurology/sleep vein:

somnium
"the dream" — Kepler's Somnium, the first sci-fi story about a journey to the moon. A vision of what could be.
oneiros
"dream personified" — Greek mythology, the god of dreams.
parasomnia
"sleep-behavior disorder" — the agent that acts while you sleep. Building, previewing, deploying.

The line is gated in canon — "surface only when real." This concept is real enough to name.
